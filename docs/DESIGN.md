# DESIGN.md

> 시각적 디자인 원칙입니다. 기술 블로그의 미적 기준을 정의합니다.

## 핵심 원칙

- **가독성 최우선** — 긴 글을 편하게 읽을 수 있어야 한다
- **콘텐츠 중심** — 크롬(UI 요소)이 콘텐츠를 방해하지 않는다
- **일관성** — 동일한 요소는 항상 동일하게 보인다

## 타이포그래피

| 용도 | 폰트 | 크기 |
|------|------|------|
| 본문 | (미정 — 논의 필요) | 16–18px |
| 제목 | (미정) | — |
| 코드 | 모노스페이스 | 14–15px |
| 홈 목록 페이지 제목 | Pretendard | 48–60px |
| 홈 게시글 카드 제목 | Pretendard Semibold | 20px |
| 홈 리스트 카드 제목 | Pretendard Semibold | 24px |
| 홈 게시글 메타 | Pretendard Medium/Semibold | 14px |

## 컬러

- 다크 모드 & 라이트 모드 모두 지원
- 색상 팔레트: (기술 스택 확정 후 정의)
- 홈 목록 UI는 현재 흑백 토큰만 사용한다.
  - 배경: `--background`
  - 주요 텍스트: `--foreground`
  - 보조 텍스트: `--muted-foreground`
  - 구분선/선택 테두리: `--border`

## 레이아웃

- 본문 최대 너비: 680–760px (읽기 편한 라인 길이)
- 좌우 여백: 충분히 확보
- 페이지와 헤더의 외곽 컨텐츠 영역은 `max-width: 1440px`로 제한한다.
- 이 외곽 컨텐츠 영역은 가로 폭을 꽉 채우고, 내부에서 본문 읽기 폭만 별도로 제한할 수 있다.
- 헤더 높이는 `64px`로 고정하고 sticky 위치만 유지한다.
- 홈 게시글 목록은 데스크톱에서 3열 그리드를 기본으로 하며, 리스트 보기 전환 UI를 제공한다.
- 홈 게시글 썸네일 비율은 그리드 `16:11`, 리스트 `16:10`을 기준으로 한다.
