# docs/exec-plans/active/README.md

> 현재 진행 중인 작업 단위 실행 계획 목록입니다.

## 현재 상태

- 현재 활성 실행 계획 없음

## 시작 규칙

- 사용자 요청을 처리할 때마다 먼저 작업 단위 실행 계획 문서를 이 디렉터리에 추가한다
- 계획에는 목표, 범위, 변경 대상, 검증, 종료 조건이 포함되어야 한다
- `docs/PLANS.md`의 마일스톤 전체를 복제하지 말고 실제 실행 범위만 기록한다
- `worktree` 준비와 구현은 계획 기록 이후에만 시작한다

## 운영 규칙

- 이 디렉터리에는 진행 중인 실행 계획만 둔다
- 작업이 끝나면 결과를 적고 `../completed/`로 이동한다
- 진행 중이 아닌 계획이 남아 있으면 stale로 보고 즉시 정리한다
- `docs/PLANS.md`와 상태가 어긋나지 않게 함께 갱신한다
