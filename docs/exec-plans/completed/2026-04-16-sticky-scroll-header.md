> 머지 상태: 이 작업을 포함한 커밋을 `develop`에 병합함

## 목표

스크롤 전에는 경계선 없이 자연스럽게 보이고, 스크롤 후에는 검은 배경과 흰 글씨로 전환되며 화면 상단에 계속 고정되는 sticky 헤더를 자연스러운 애니메이션과 함께 구현한다.

## 범위

- 전역 헤더를 sticky 동작으로 전환
- 스크롤 위치에 따라 헤더 배경, 테두리, 텍스트 색상 상태 전환
- 상태 전환 애니메이션 적용
- 위 동작을 검증하는 자동화 테스트 추가 또는 갱신
- 작업 완료 후 localhost가 새 변경을 보도록 dev 서버 재기동

## 제외 범위

- 페이지 본문 레이아웃 재설계
- 새로운 네비게이션 항목 추가
- 헤더 외 다른 섹션의 인터랙션 변경

## 변경 대상

- `tests/`

## 종료 조건

- 헤더가 상단에 sticky로 유지된다
- 초기 상태에서 헤더 테두리가 보이지 않는다
- 스크롤 시 헤더가 검은 배경과 흰 글씨로 자연스럽게 전환된다
- 자동화 테스트가 추가되거나 갱신된다
- 빌드, 린트, 테스트가 모두 통과하고 localhost에 변경이 반영된다
