# 홈 게시글 목록 레이아웃 개편

> 상태: 완료
> 종료일: 2026-04-28

## 목표

홈 화면을 랜딩 페이지가 아닌 게시글 목록 중심 화면으로 개편하고, 헤더와 공통 컨텐츠 폭 규칙을 1440px 기준으로 정리한다.

## 범위

- 모든 페이지와 헤더 내부 컨텐츠 영역의 최대 너비를 1440px로 제한한다.
- 헤더 높이를 64px로 고정하고 스크롤 상태에 따른 색상 변경을 제거한다.
- 홈 화면에 카테고리 탭, 필터/정렬/보기 전환용 레이아웃, 게시글 목록을 배치한다.
- 게시글 목록은 그리드 3열과 리스트 형태로 전환 가능한 UI 구조를 제공한다.
- 이번 작업에서 확정되는 글자 크기, 색상, 레이아웃 토큰을 디자인 문서에 기록한다.

## 제외 범위

- 실제 필터링, 정렬, 카테고리별 데이터 조회 로직 완성
- 조회수의 실제 집계/저장 기능
- 상세 게시글 페이지 디자인 개편

## 변경 대상

- `app/`, `components/`의 홈 화면 및 헤더 관련 UI
- 필요 시 `runtime/`의 게시글 목록 데이터 노출부
- 디자인 시스템 문서
- UI 동작 또는 렌더링 테스트

## 검증

- 문서 링크와 디자인 토큰 기록 정합성 확인

## 종료 조건

- 홈 화면이 요청한 게시글 목록 레이아웃을 제공한다.
- 헤더 내부 폭, 높이, sticky 동작이 요구사항과 일치한다.
- 관련 테스트와 검증이 통과한다.

- 홈 화면을 게시글 목록 중심 화면으로 교체했다.
- 헤더는 64px sticky 헤더로 유지하고 스크롤 색상 변경 상태를 제거했다.
- 페이지, 헤더, 푸터 외곽 컨텐츠 영역을 1440px 기준으로 맞췄다.
- 홈 게시글 목록에 카테고리 탭, 필터/정렬 버튼, 그리드/리스트 보기 전환 UI, 썸네일/제목/카테고리/게시일/조회수 메타를 배치했다.
