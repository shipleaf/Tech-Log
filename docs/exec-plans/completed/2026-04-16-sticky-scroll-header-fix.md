## 목표

스크롤 중에도 사이트 헤더가 화면 상단에 계속 고정되도록 sticky 동작을 바로잡고, 해당 동작을 자동화 테스트로 고정한다.

## 범위

- 기존 sticky scroll header 구현의 실제 DOM/CSS 동작 원인 분석
- 헤더가 상단에 고정되지 않는 레이아웃 또는 스타일 문제 수정
- sticky 유지와 스크롤 상태 전환을 검증하는 테스트 추가 또는 갱신
- 수정 후 관련 검증 수행

## 제외 범위

- 헤더 디자인 전면 재작업
- 네비게이션 구조 변경
- 헤더 외 다른 레이아웃 인터랙션 수정

## 변경 대상

- `app/`
- `components/`
- `tests/`
- `docs/exec-plans/active/`

## 검증

- `npm run build`

## 종료 조건

- 헤더가 스크롤 중에도 뷰포트 상단에 유지된다
- 스크롤 전/후 시각 상태 전환이 기존 의도대로 동작한다
- 관련 자동화 테스트가 동작을 고정한다
- 빌드, 린트, 테스트가 모두 통과한다

## 완료 결과

- 헤더 상위 레이아웃 래퍼의 `overflow-x-hidden`이 sticky 기준을 깨뜨릴 수 있는 구조여서 제거했다
- 가로 넘침 방지는 sticky를 방해하지 않는 `body`의 `overflow-x-clip`으로 옮겼다
- 전역 레이아웃 테스트에 sticky 헤더를 막는 overflow 회귀 가드를 추가했다
