## 목표

게시글 상세 페이지에서 제목 영역과 본문을 감싸는 카드형 border UI를 제거하고, 제목/설명/작성 시간/읽기 시간을 가운데 정렬된 읽기 중심 헤더로 재구성한다. 아직 기능은 없지만 추후 조회수와 좋아요 수를 자연스럽게 노출할 수 있는 메타 영역도 함께 배치한다.

## 범위

- 게시글 상세 페이지의 외곽 card/border 스타일 제거
- 제목, 설명, 작성일, 읽기 시간의 정렬과 간격 재구성
- 조회수/좋아요 수 자리표시 메타 UI 추가
- 위 레이아웃을 고정하는 자동화 테스트 추가 또는 갱신

## 제외 범위

- 조회수/좋아요 실제 집계 기능 구현
- 목록 페이지 카드 디자인 변경
- MDX 본문 타이포그래피 전면 수정
