## 핵심 가치 제안

**"개발자인 나의 생각과 경험을 명확하게 기록하고 공유하는 공간"**

- 빠르게 로드되고, 읽기 편하고, 기술 콘텐츠를 잘 표현한다
- 방문자가 아닌 **나 자신을 위해** 먼저 쓴다
- 지속 가능하게 유지보수할 수 있다

## 타겟 독자

1. **미래의 나** — 과거 문제 해결 과정을 빠르게 찾기 위해
2. **비슷한 문제를 가진 개발자** — 검색을 통해 유입
3. **채용 담당자 / 협업 대상** — 포트폴리오로서

## 성공 지표

- Lighthouse 성능 90+
- 포스트 작성 → 발행까지 마찰 최소화
- 6개월 후에도 유지보수 부담 없음
