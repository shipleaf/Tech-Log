# FRONTEND.md

> UI 컴포넌트 규칙 및 코딩 컨벤션입니다.
> 기술 스택 확정 후 세부 내용이 채워집니다.

## 컴포넌트 원칙

- 컴포넌트는 단일 책임을 가진다
- Props는 명시적 타입을 가진다
- 스타일은 컴포넌트와 함께 위치한다 (co-location)

## 접근성

- 모든 이미지에 alt 텍스트
- 키보드 내비게이션 지원
- 색상 대비비 WCAG AA 이상

## 성능

- 이미지 lazy loading 기본 적용
- 폰트 서브셋 사용
- 불필요한 클라이언트 JS 최소화

## 컨벤션

| 항목 | 규칙 |
|------|------|
| 컴포넌트 파일명 | PascalCase |
| CSS 클래스 | kebab-case (또는 스택 결정 후 업데이트) |
| 테스트 파일 | `*.test.ts` 또는 `*.spec.ts` |
